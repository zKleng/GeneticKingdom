# Genetic Kingdom

**Genetic Kingdom** is a 2D tower defense game implemented in C++ using SFML.  
Enemies navigate the map to reach your castle, while the player defends with strategically placed towers. 


**Dependencies**

This project requirements:

- **C++17** compatible compiler  
- **CMake** ≥ 3.10  
- **SFML** 2.5.x or newer (SFML 3.0+ supported with manual linking)


**Compilation**

To compile and run, use the following commands:
In /build:
    -cmake ..
    -make
    -make run

To delete compiled file in build and bin:
In /build:
    -make clean-all


Optional running method, in the root:
Linux & MacOs: ./bin/GeneticKingdom
Windows: .\bin\GeneticKingdom.exe
